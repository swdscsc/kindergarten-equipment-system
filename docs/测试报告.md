## 3. 开发过程中的缺陷与修复记录

| # | 缺陷 | 根因 | 修复 | 回归 |
|---|------|------|------|------|
| 1 | 看板页 500 | SQL 字符串中误含 `]` 字符导致 LIKE 子句语法错误 | 修正 SQL | 通过 |
| 2 | 登记报修 500 | INSERT 列与占位符数量不匹配（finish_date/status/cost 传参错位） | 改为显式 `NULL,'待派单',0` | 通过 |
| 3 | 更新维修单 500 | sqlite3.Row 列表被当作字典索引（`row["finish_date"]` 作用于 list） | 取 `rows_[0]` 后再索引 | 通过 |
| 4 | Excel 导出抛 TypeError | openpyxl 不接受 `cell.border = cell.border`（StyleProxy 不可哈希） | 删除无效赋值 | 通过 |

> 缺陷 1—3 均由本测试套件首轮运行暴露：首轮 `4 failed, 16 passed`，修复后 `20 passed`。
