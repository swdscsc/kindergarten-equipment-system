园务设备管理系统

幼儿园集团办公自动化与数据报表系统 · 项目展示页

Python Flask · SQLite · Chart.js · openpyxl · pytest 20 用例通过
声明：本项目为个人技术演示作品，全部数据为虚构示例，不代表任何真实幼儿园的实际使用情况。

这是什么

一个真实可运行的设备管理信息系统：设备台账、维修记录状态流转、实时统计看板、一键导出带公式的 Excel 报表； 并以系统数据为源，自动产出 Word 月度报告、PPT 培训课件与《Excel 数据录入规范》，形成"系统 + 制度 + 培训"的完整行政信息管理方案。

管理看板

6 项 KPI + 柱状 / 环形 / 折线三类图表，报修、维修、费用实时联动刷新。

设备台账

32 台设备的三园资产档案，园区 / 状态 / 关键字多维筛选，编号唯一校验。

维修记录

报修单号按月自动编号（WX-2610-05），待派单 → 维修中 → 已完成状态机，与设备状态双向联动。

Excel 报表引擎

导出的工作簿含活公式、数据验证与条件格式，经 LibreOffice 重算 204 个公式零错误。

快速运行

git clone https://github.com/swdscsc/kindergarten-equipment-system.git
cd kindergarten-equipment-system
pip install -r requirements.txt
python run.py          # http://127.0.0.1:5177
python -m pytest tests/ -v   # 20 passed
